# Keyboard shortcuts

Shortcuts work on the workspace screen, except while typing in the search box or a dropdown, while a dialog is open, or with Ctrl, Alt or Cmd held. They're handled in `bindKeys` in `main.ts`.

| Key | Action |
| --- | --- |
| 1–5 | Rate the current song |
| 0 or Backspace | Clear the current song's rating |
| Space | Play or pause; with nothing playing, start from Resume |
| → / ← | Forward or back 15 seconds |
| Shift + → / Shift + ← | Next or previous song |
| N | Next song |
| M | Jump to 45% through the song |
| / | Focus the search box |
| Esc | Clear the selection |

While waiting for a rating, Space and → do nothing; rate the song, or use ← or M to hear part of it again.
